Game compatibility

Every game was started in Orbit64 and played automatically. The tester presses A or START only when the game reacts to them, and finally checks whether the stick moves the character or the camera.

0games

These results are not 100% certain. Every game is played by an automatic tester, so it can be wrong: a game shown as Menu or Intro / title may work fine and the tester just didn't find its way further, and the other way round. Menu and Intro / title do not mean the game is broken: in many of those games the emulator works fine and the tester simply doesn't reach gameplay (it can't pick a mode or a character, needs a specific button sequence, a save, or a longer wait). The results are still being checked by hand and will be corrected; games checked by hand are marked checked. If you know a game's real state, please tell us.

How the status is decided

The tester runs each game with save states: from the same moment it tries the game without input, with A, with START and with the stick held, and compares the pictures. A game that reacts to a button gets that button; a game that doesn't react is left alone (logos, cut-scenes, loading). Then it looks at the last seconds. The automatic verdict is then compared with the screenshots by eye and corrected where it is wrong; this is still in progress, so many games are not checked yet.

  • In-game – the stick moves the character or the camera: gameplay.
  • Menu – the game reacts to buttons or a cursor, but the tester didn't get into gameplay. The game may well work.
  • Intro / title – logos, intro, title screen or demo, no control yet. The game may well work.
  • Black screen – nothing (or only black) is shown.
  • Crash / error – the emulator crashed or timed out, the game froze, or the picture is broken.
  • HLE / LLE – HLE is the default, fast emulation. LLE runs the game's own RSP microcode with a bit-exact RDP: slower, more compatible. A game is tried in HLE first, in LLE only when HLE doesn't get into the game.

"In-game" is not "perfect": glitches, missing effects and slowdowns are not measured here. The run is short (about a minute of game time), so a game that needs a long intro, a choice in a menu or a specific button sequence to reach gameplay can show up as Menu or Intro even though it runs fine. Only Black screen and Crash / error point to a problem in the emulator with any likelihood, and even those are checked by hand before they are treated as such.
