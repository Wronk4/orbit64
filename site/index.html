Orbit64

A free, open-source Nintendo 64 emulator for Windows, macOS and Linux. It has a dynamic recompiler, renders at up to 8× the original resolution on the GPU, and supports save states.

Download the latest release Source code on GitHub

Features

Dynamic recompiler

Translates MIPS code to native AArch64 or x86-64 code and falls back to the interpreter for anything it doesn't handle.

Internal resolution 2×–8×

Draws every triangle again at a higher resolution in SDL_GPU compute shaders (Metal, Vulkan, Direct3D 12). This is not an upscaled image.

Save states

Nine slots per game with screenshots, plus undo for the last load. States follow the game when you rename or move the ROM.

Audio HLE

Emulates the libultra, n_audio, Nintendo EAD and Factor 5 MusyX audio microcodes and resamples with a windowed-sinc filter.

Game library

Scans your ROM folders, shows box art, and keeps favorites, recently played games and play time.

Debug tools

Includes an object viewer, memory search, RAM watch, a memory editor, freeze lists and frame stepping.
