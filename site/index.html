Orbit64: a Nintendo 64 emulator for Windows, macOS and Linux

Play your N64 games in sharp HD. Orbit64 recompiles N64 code to native code, renders 3D at up to 8× the original resolution on your GPU, and saves your progress at any moment with save states.

Features

Orbit64 is a desktop app. It emulates the N64's CPU, RSP and RDP, with a modern game library and tools on top.

Fast JIT recompiler

Translates the N64's MIPS code to native ARM64 or x86-64 code and chains blocks together. It falls back to the interpreter for anything it doesn't handle.

HD internal resolution

Renders 3D at 2× to 8× the original resolution in GPU compute shaders on Metal, Vulkan or Direct3D 12. Every triangle is drawn again at the higher resolution; the image is not upscaled.

Save states

Nine slots per game, each with a screenshot and a timestamp, plus undo for the last load. Saving takes about a millisecond, and states stay with the game when you rename or move the ROM.

Accurate audio

Emulates the libultra, n_audio, Nintendo EAD and Factor 5 MusyX audio microcodes, then resamples the sound with a 32-tap windowed-sinc filter so the pitch is never bent.

Controllers and keyboard

Xbox, PlayStation, Switch Pro and other SDL3-supported gamepads work out of the box. You can rebind every button and stick direction.

Game library

Scans your ROM folders and shows box art from No-Intro / RetroArch packs. It keeps favorites, recently played games and play time.

Debug and memory tools

Includes a 3D object inspector, memory search, RAM watch, a memory editor, freeze lists, frame stepping and turbo, for curious players and ROM hackers.

Frame buffer effects

The game still gets its normal frame buffer in memory. Effects that read it back, like motion blur, pause screens and CPU-drawn images, keep working in HD.

Real HD rendering, not an upscale

Most N64 games render at 320×240. Stretching that image to a 4K screen only makes it blurry. Orbit64 records every triangle, texture rectangle and fill the game draws and draws them a second time at the resolution you choose, with its own depth buffer and 8 bits per colour channel.

  • 2×, 3×, 4× up to 8× internal resolution (up to 2560×1920)
  • Rendered in GPU compute shaders; the frame stays in video memory
  • The same colour combiner, blender and texture decoding as the software renderer
  • Falls back to a multi-threaded CPU renderer on machines without a usable GPU driver
  • Change it in Settings › Graphics or in the View menu while you play

Getting started

  1. Download the file for your system and unpack it.
  2. Start orbit64 (orbit64.exe on Windows).
  3. Add the folder with your ROMs (.z64, .n64, .v64) to the library.
  4. Double-click a game. Plug in a controller or use the keyboard.

macOS: first launch

The app is not notarized yet, so macOS blocks it the first time. Run this once in Terminal, in the folder where you unpacked it:

xattr -dr com.apple.quarantine orbit64

Frequently asked questions

Answers to common questions about Orbit64.

Is Orbit64 free?

Yes. Orbit64 is free to download and use, and its source code is on GitHub.

Does Orbit64 run on Apple Silicon Macs?

Yes. The macOS build is a universal binary. On M1, M2, M3 and newer Macs the recompiler generates native ARM64 code, and the GPU renderer uses Metal.

Do I need an N64 BIOS or PIF ROM?

No. Orbit64 emulates the boot process itself, so a ROM file (.z64, .n64 or .v64) is all you need.

Does Orbit64 include games?

No. Orbit64 ships without any games. Use ROMs that you dumped from cartridges you own.

Can I play with a controller?

Yes. Xbox, PlayStation, Switch Pro and other controllers that SDL3 supports work out of the box, and every button can be rebound in Settings. You can also play on the keyboard.

What does internal resolution do?

It renders every triangle and texture at 2× to 8× the game's original resolution on the GPU, so 3D graphics look sharp on modern displays. It is not an upscale of the finished 320×240 image.

Where are my saves and settings stored?

In your user config folder: %APPDATA%\Orbit64 on Windows, ~/Library/Application Support/Orbit64 on macOS and ~/.local/share/Orbit64 on Linux. Set ORBIT64_CONFIG_DIR to keep everything in a portable folder instead.

Build from source

The only dependency is SDL3 3.4 or newer, and CMake downloads it for you when it isn't installed. See the README for every platform.

git clone https://github.com/Wronk4/orbit64.git
cd orbit64
cmake -S . -B out -DCMAKE_BUILD_TYPE=Release
cmake --build out
